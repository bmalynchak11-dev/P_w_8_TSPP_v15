# Практична робота 8: ШІ-асистент у роботі над беклогом і тестами

Структура, правила задач і картки варіантів описано в документі студента (PDF у завданні Google Classroom).

Швидкий старт:
1. Створіть середовище й встановіть залежності: `python -m venv .venv`, потім `source .venv/bin/activate` і `pip install -r requirements.txt`.
2. Визначте номер задачі та набору за номером у журналі й відкрийте `variants/variant_NN.py`.
3. Запускайте відкриті тести: `pytest tests/test_variant_NN.py`.
4. Частина Б: заповніть файли теки `my_ai/` за прикладом із `my_ai/format_example/` і перевірте їх командою `pytest check -q`.

Дані контекстів (відповіді асистента зафіксовано у файлах): `data/context_N_*.json`. Мережа й зовнішні моделі в задачах частини А не потрібні.
